# Movie Watchlist Manager (MERN)

A full-stack Movie Watchlist Manager built with MongoDB, Express, React and Node.js.

## Important setup note
The included `.env` uses a **placeholder Atlas connection string** for safety. Replace `MONGODB_URI` with your own MongoDB Atlas URI before starting the backend. Do not commit real database passwords. The exam instructions request a `.env` file; this repository includes one with dummy values, not working credentials.

## Requirements
- Node.js 18+
- MongoDB Atlas cluster and database user
- Git

## Run in VS Code

### 1. Configure MongoDB Atlas
1. Create a free Atlas cluster and database user.
2. In Atlas Network Access, allow your current IP address.
3. Copy the Node.js connection string.
4. Edit `backend/.env` and replace the `MONGODB_URI` value. URL-encode special characters in the database password.
5. Set `DB_NAME=movie_watchlist` if desired.

### 2. Start backend
```bash
cd backend
npm install
npm run dev
```
Backend runs at `http://localhost:5000`.

### 3. Start frontend (new terminal)
```bash
cd frontend
npm install
npm run dev
```
Open the URL printed by Vite (usually `http://localhost:5173`).

## APIs
All responses use `{ "success": boolean, "message": string, "data": ... }`.

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/movies?status=&genre=&search=&page=1&limit=6` | Filter, search and paginate movies |
| POST | `/api/movies` | Add movie; code generated by backend |
| GET | `/api/movies/:id` | Get one movie |
| PUT | `/api/movies/:id` | Edit title, genre, runtime, platform, priority |
| PATCH | `/api/movies/:id/status` | Change status; requires rating when moving to Watched |
| PATCH | `/api/movies/:id/rating` | Edit rating for Watched movie only |
| DELETE | `/api/movies/:id` | Delete unless status is Watching |
| GET | `/api/movies/watch-next` | Highest-priority To Watch movie; shortest runtime breaks ties |
| GET | `/api/stats` | Status totals, watched hours, average rating, top watched genre |

## Implemented rules
- Release year: 1950 through current year; runtime: 30–300 minutes, validated on client and server.
- Unique title + release year (case-insensitive).
- Movie code `MV-<year>-<3-digit sequence>`, sequential per year and generated only on the backend.
- Status workflow: To Watch → Watching/Watched; Watching → Watched/To Watch; Watched is final.
- Rating 1–10 required when marking Watched; watched date set by backend. Ratings cannot be set on non-Watched movies.
- 6 items per page by default; total page count returned.
- To Watch results sort by priority descending first.
- Watching movies cannot be deleted.
- Statistics are fetched again after mutations.
- Responsive layout for desktop and mobile.
